## NW-20 — 360 `benchmark` / `activity` always `[]` · `should`, position 4

- **IN but bounded** — both are spec §8.2 `:367` tab names, so neither is a new
  capability; the missing piece is a definition, which is this seat's.
- **"Activity" for V1 = the provenance timeline, drawn only from events already
  persisted**: uploaded / processing completed / `document.validated` /
  `document.reprocessed`, contract correction, renewal action started or
  assigned, negotiation step ticked, savings outcome recorded. Each entry: when,
  actor (ADR-011's convention, `system:<component>` for pipeline events), what
  changed — **never the value of an extracted fact**. **Out**: supplier
  communication or outreach (§1.2 non-goal; pilot `:153`), notes/comments, and
  anything needing a new table.
- **Honest alternative if that projection does not fit the wave**: **remove
  `activity` from the payload and delete the memberless record type** rather
  than ship an array that can never fill — a named tab that never lights up is
  w14 clause 3 inverted. **Unacceptable: leaving an unconditional `[]` with no
  decision.** `benchmark` has no such option — NW-62 consumes it.
- **N16 on `dev`**: a contract with a validated end date and a processed
  document returns a non-empty `benchmark` (or the explicit insufficient-data
  marker of NW-22) and an `activity` whose every entry traces to a persisted
  event — or no `activity` member at all.
- **ADR action**: `amend ADR-001` clause 3. Payload shape is
  software-architect's.

mint a task*. **OUT for V1**, on four oracle grounds:

   `buildTrackedOpportunityRow`.

   tracker (`:105-108`). A third surface adds no user-visible outcome
   (ADR-001 `:84-85`).
3. **The pilot puts this surface out of the demo** (`percorso-pilota-v1.md:148`,
   §5 `:108`). NW-72 is already this wave's Savings work, and it closes a real AC.
4. **It is `could` and overflow.** OUT removes it from the live set instead of
   parking it, freeing W18's head for NW-63's deferred half (OQ-w17-001).

**Re-entry condition** (a ruling, not a refusal): it returns as a **new item**
once a tracked action can carry a system-held estimate — i.e. after NW-62's
benchmark join (OQ-w17-004). Not before, and never as a pseudo-row.
