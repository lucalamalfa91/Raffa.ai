## NW-63r — bounding-box overlay + phrase-edit (cloud half: the gateway model)

**Decision.** No new Azure resource, no new SKU, no new role assignment, no new
model deployment in either environment. The cloud delta of NW-63r is **one
string** in `modules/foundry`: the `ocr` role's bound model widens from
`prebuilt-read` to `prebuilt-layout`. Everything else the item's "four pieces"
need is software-architect's wire/geometry/migration and client-architect's/UX's
viewer side — none of it is Azure surface.

**Why no SKU move — verified, not assumed (OQ-w18-005 answered on the `none`
branch).** Document Intelligence is **native to the shared AI services account**:
`infra/modules/foundry/main.tf` binds the `ocr` role **inside the module**, not
via a deployment resource —

```
local.ocr_model_id      = "prebuilt-read"      # modules/foundry/main.tf (~:40)
local.ocr_model_version = "2024-11-30"
# role_model merges: ocr = { id = local.ocr_model_id, version = local.ocr_model_version }
```

`prebuilt-read` and `prebuilt-layout` are **built-in models** on the account —
they are **not** `azurerm_cognitive_deployment` resources (only the four chat/embed
roles `classify/extract/embed/answer` are deployments, per `variable "model_roles"`
validation). So switching to `prebuilt-layout` is the `ocr_model_id` local, **not**
a new deployment, not a new account, not a second AI services subscription.

The workload identity already holds **`Cognitive Services User`** on the account
(`azurerm_role_assignment.workload_ai_services_user`, scope = account id) — that is
the Document Intelligence **data plane** role, and Layout vs Read does not change
which role is needed. `Cognitive Services OpenAI User` governs chat inference only.
**No new role assignment** is owed for either environment.

**Per-env project/connection unchanged.** The `conn-docint-raffa-<env>` header
value (`local.document_intelligence_connection`) is informational and stays
`prebuilt`-agnostic.

**ADR action.** `amend ADR-017` (the `ocr` role requirement sentence "Read …
Layout/sections/tables" and its `:103` rule — but see "boundary" below: the
*decision* lives in ADR-017 which software-architect co-owns; this seat's ADR-005
holds the **cost** line). Record the cost consequence as an ADR-005 footer
(clause continuation): `prebuilt-layout` is metered at a higher per-page rate than
`prebuilt-read`, applied per page over the same page budget
(`AiGateway:Ocr:MaxPagesPerDocument`). **ADR-008: `none`** — the account shape is
unchanged; OQ-w18-005 is answered "already on the account".

**Cost line.** `prebuilt-layout` per-page rate is higher than `prebuilt-read` and
is applied to every page the `ocr` role touches (ADR-017: every PDF/image). It is
still **usage-metered with no idle/fixed charge** — no new fixed monthly line in
either environment; the two non-trivial fixed lines (Service Bus Standard, ACR
Basic, ADR-005 `:56`) are unchanged. Retail per-page prices for
`prebuilt-read` vs `prebuilt-layout` (North Europe, S0) are owed by the infra cost
researcher **only when the model string actually flips** — the change is two
characters in one local, and if the council decides Layout is not needed for the
overlay the string never moves.

**Config keys — the environment already exposes none and adds none.** The `ocr`
model id/version are published through `model_env`
(`AiGateway__Models__Ocr__ModelId` / `__ModelVersion`) only when
`publish_endpoint` is true; the value simply changes from `prebuilt-read` to
`prebuilt-layout`. **No new env var name is added in either environment.** The
`AiGateway__DocumentIntelligenceConnection` header value is unchanged.

**Boundary (handed to software-architect, not decided here).** Whether the overlay
actually needs `prebuilt-layout` (vs anchoring with the existing `SourcePage` +
`SourceSpan` + adding `words`/`polygon` from Read's analyze result) is a
**contract question**, not a cloud one. This seat's finding is binary and narrow:
*if* Layout is called, the cloud change is the `ocr_model_id` local and nothing
else; the cost consequence is a per-page rate increase, not a fixed line.

**Order constraint.** If the `prebuilt-layout` string flips, it rides the wave's
infra PR **before** the backend image that reads `AiGateway__Models__Ocr__ModelId`
merges — same HARD shape as ADR-005 w15 §8: the key is published by Terraform, and
`backend.yml` deploys `az containerapp update --image` only. If Layout is **not**
needed, the infra delta is `$0.00` and there is no ordering at all.
