# task-01-audit-read-for-a-real-admin — Swap the guard to membership; publish the route

> **Queued for W16.** No entry in `reports/plan/slices/w15.yaml`; not fanned out
> this wave.

## Coding objective

Make `GET /api/audit` reachable by the people it exists for. Replace the
claims-based guard at `AuditEndpointExtensions.cs:22-36` — which calls
`WorkspacePrincipalAuthorization.TryAuthorize` and therefore needs a custom
`tenant_id` claim and a `ClaimTypes.Role` that ADR-010's w14 footer forbids as an
authorization source — with the **membership** resolution every other
tenant-scoped route uses. Then add the path to
`web/openapi/raffa-api.v1.json`, which today has 34 paths and no `/api/audit`, so
no generated client can reach it even once the guard is fixed.
