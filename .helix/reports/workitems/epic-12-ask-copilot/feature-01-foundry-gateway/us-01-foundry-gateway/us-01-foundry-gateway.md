# us-01-foundry-gateway — Live Foundry behind IAiGateway

## Story

As **procurement**, I want Ask and extraction to call Foundry when the
environment is wired, so answers are generated by a model — not a chunk dump.

## Acceptance criteria

- [ ] AC-1 With `AiGateway:Endpoint` set, `IAiGateway` is a Foundry-backed
      implementation wrapped by `LoggingAiGateway`.
- [ ] AC-2 With the endpoint unset, the fixture gateway still resolves
      (tests and local).
- [ ] AC-3 No Azure AI SDK reference exists outside `Raffa.AiGateway`.

## Definition of done

- [ ] every AC above is verified by at least one test named in a task
- [ ] the change honours ADR-004 / ADR-023
- [ ] no open question blocking this story is unresolved and unassumed
